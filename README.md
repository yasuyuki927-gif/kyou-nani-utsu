# 今日なに打つ？

パチンコ・パチスロで今日打つ機種をランダムに選ぶ、スマホ向けの自分用メモWebアプリです。

## 特徴

- 機種名、パチンコ/スロット、タイプ、優先度、荒さ、店舗メモを登録できます。
- 設定示唆、天井、ゾーン、やめどきは自分用メモとして手入力できます。
- ちょんぼりすたの解析ページはURLだけ登録できます。
- 「今日の1台を抽選」ボタンで、登録機種からランダムに1台を表示します。
- 優先度が高い機種ほど抽選で出やすくなります。
- 抽選結果には機種名、自分用メモ、「ちょんぼりすたで確認」ボタンを表示します。
- 収支記録を保存できます。
- データはブラウザのlocalStorageに保存されます。
- ログインは不要です。
- iPhoneで見やすい縦長デザインです。

## 重要な運用ルール

このアプリは外部サイトの内容を自動取得しません。ちょんぼりすたの記事本文、表、数値、画像はコピーせず、機種ごとにURLだけを保存する設計です。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。

## ビルド

```bash
npm run build
npm start
```

## 使い方

1. 「機種登録」から機種名、種別、タイプ、優先度、荒さ、各種メモ、ちょんぼりすたURLを入力します。
2. 「機種を保存」を押します。
3. 「今日の1台を抽選」を押すと、登録済み機種から1台が表示されます。
4. 抽選結果の「ちょんぼりすたで確認」ボタンから、登録したURLを別タブで確認できます。
5. 実戦後は「収支記録」に日付、機種名、投資、回収、実戦メモを保存できます。
